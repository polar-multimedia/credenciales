# Credenciales Polar

Presentaciones de credenciales de Polar Multimedia, una carpeta por cliente.

- `comun/` — imágenes, videos, fuentes y cuadros que comparten todas las presentaciones. Se suben una sola vez.
- `<cliente>-<código>/index.html` — la presentación de cada cliente. El código al final evita que se adivinen las ligas de otros clientes.
- Todas las páginas llevan `noindex` para que no aparezcan en buscadores.

Si una presentación nueva necesita una versión distinta de un archivo que ya existe en `comun/`, debe llevar otro nombre para no cambiar las demás.
